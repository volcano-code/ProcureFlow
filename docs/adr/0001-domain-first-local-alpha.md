# ADR-0001：先锁定业务不变量，再替换运行时

状态：本轮 Alpha 已采纳。

背景：原计划技术栈合理，但当前开发环境无法下载 npm 依赖，没有 Docker/PostgreSQL/真实 ERPNext 和模型账户授权。继续用“已完成第一周”描述空目录会产生虚假进度；强行模拟所有框架同样没有工程意义。

决定：先交付可执行、可测试的业务服务，以 SQLite 和明确标注的独立 mock ERP 验证证据、金额、审批和执行协议；提供不依赖 Node 的 UI，同时编写原生 Next.js 源码，但分别披露验证状态。

模型接入采用 opt-in 只读有界循环，业务写入只经审批服务。运行时可在后续迁移到 LangGraph，但其执行状态不能取代业务数据库授权。

后果：第一版容易本地运行和复现，但不能称作目标架构已经落实。PostgreSQL、Celery、LangGraph、MCP、AG-UI 与真实 ERP 联调仍须独立退出条件。模拟回执只证明模拟合同，不证明真实系统兼容。阻断的构建或浏览器测试如实记录，不能计为成功。
