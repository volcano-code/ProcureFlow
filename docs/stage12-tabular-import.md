# 阶段十二：普通 CSV / XLSX 报价导入

## 支持范围

普通 UTF-8 / UTF-8 BOM CSV（逗号、分号或制表符）和不带宏/外链的 XLSX。
常见中英文表头仅提供映射建议，不提供业务确认。原生 Next 工作台提供独立“导入普通表格”入口；原有 TXT、两列 CSV、文本 PDF、A/B 键值 XLSX 入口保留。

用户明确选择一个工作表、表头行、一个报价数据行以及每个字段的来源列。支持文件内多个可选行/工作表，但一次只读取选中的一行，不合并其他商品、其他行或其他工作表的金额。所选 SKU 必须匹配需求；仅接受 CNY、EA，单个 SKU/币种单元格内的多值歧义拒绝。未提供 SKU/币种/单位仍保持未知，不从需求复制填充。

没有 OCR、合并多 SKU 采购、币种转换、公式计算、真实模型调用或生产 ERP 操作。

可复现的普通供应商式合成文件位于 `evals/fixtures/tabular/`：CSV 和中英文双工作表 XLSX，可按该目录说明手工走完预览/映射/确认流程。

## 两层显式确认

1. 上传仅创建持久预览，不生成报价，不改变已有采购方案
2. 选择工作表、表头/报价行及列映射，点击预览。服务器使用保存的原始表格，不接受客户端伪造单元格或来源
3. 核对提取值、未知字段、重复行/公式提示和 SHA-256 + sheet / row / column / cell 来源，再明确确认导入
4. 此时只创建一份“未确认报价”。纠错继续使用现有带 reason 的新报价版本；核对后显式确认该版本
5. 比较、审批、ERP 草稿继续走已有 Decimal 成本计算、租户政策、完整报价集合/证据版本快照和独立审批权限

缺失运费、折扣、税价模式和其他字段不会默认为零。公式与错误单元格不采用缓存值。没有足够信息的报价即使确认也不能绕过成本/交期/政策资格检查。映射本身不能赋予文件业务授权。

## API 与持久化

- `POST /api/v1/requests/{id}/table-imports`：multipart 文件 → 持久预览
- `GET /api/v1/table-imports/{id}`：权限校验后的原状态读回；显示是否过期及是否已创建报价
- `POST /api/v1/table-imports/{id}/preview`：`expected_revision`, `sheet`, `header_row`, `row`, `mapping`
- `POST /api/v1/table-imports/{id}/confirm`：`expected_revision`, `acknowledge: true` → 未确认报价

`mapping` 是报价字段到唯一大写列字母的对象；未映射字段直接省略。映射和确认使用服务端 revision CAS。映射绑定当前需求 version；需求或报价集合变化后，旧预览不能直接确认，需要重新预览。确认时再次检查需求可变状态和源文件完整性。

租户、需求和源文件 SHA-256 联合唯一。重复上传复用同一预览；同一 revision 的重复/并发确认只读回已有报价，不重新创建、不清除后续人工修正。确认后想改映射，需走已有带理由的报价修正流程。旧键值入口已使用的相同源文件不能再创建第二个表格报价。

预览保存在业务数据库，源文件仅保存在私有文档目录（0600），不会提供静态下载。进程重启后可按预览 ID 读回。未导入预览 30 分钟到期；同源重新上传使 revision 增加、清空旧映射并要求重新核对。每租户最多保留 100 份未导入预览，过期记录也计入；本轮没有自动文件删除/保留管理，达到限制需要运维清理。已导入记录保留确认回执供幂等读回。

新增 Alembic revision `b9134d27c80f`，父版本 `a82d71f09c36`。不会自动迁移生产数据库或重放外部写入。

## 安全边界

普通表格解码在独立 Python 子进程中进行，不使用 shell，不继承应用环境、工作目录或额外文件描述符。旧文档入口也转为独立进程解析，保留旧提取语义。

当前硬限制：

- 上传文件 2 MiB；HTTP 接收层在 multipart 解析/临时文件 spool 前累计限制正文为上传上限 + 64 KiB，即使缺少 Content-Length；超限关闭解析中的临时文件并返回 413
- 每个 API 进程最多两个并发解析子进程，繁忙立即返回 503，不无限排队；这不是跨实例全局限流
- 解析子进程墙钟超时 5 秒，POSIX CPU 2 秒，地址空间 256 MiB，打开文件描述符 32，禁止文件写入大小与 core dump，支持时禁止创建新进程
- XLSX 最多 250 ZIP 条目、声明及实际展开量 5,000,000 字节、单条压缩比不超过 150；拒绝重复/不安全路径、加密 ZIP 条目、符号链接、宏、嵌入对象、活动内容与外部关系
- 普通表格最多 10 个工作表，每表 1,000 行、64 列，整个工作簿 20,000 个单元格、150,000 字符，每格 4,096 字符；子进程输出限制 6,000,000 字节
- XML 不接受 DTD/entity 声明或绕过扫描的 NUL/非 UTF-8 表示；不执行文档公式或代码
- Python 审计钩子在解析阶段拒绝文件打开、网络、子进程和关键文件系统变更；解码所需模块预加载；错误仅返回受控错误码/说明
- POSIX 资源限制无法启用时失败关闭，不自动回退到主进程解析

这些是进程隔离、资源限制和 Python 层防御，不是容器、seccomp、网络命名空间、文件系统权限隔离或原生代码漏洞的完整沙箱。仍需部署级反向代理字节/速率/连接限制、慢上传防护、跨 API 实例并发限制、最小权限运行账户、定期依赖审计和保留清理策略。不得据此宣称可以公开接受任意不可信文档或投入生产采购。
