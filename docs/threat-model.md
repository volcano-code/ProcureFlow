# 威胁模型：已做、已测与未解决

本项目只面向本地开发。内置演示身份、仅进程级资源隔离而非完整系统沙箱、尚未完成的生产依赖/渗透审计意味着**不得公开部署或连接真实采购生产流程**。

| 风险 | 当前控制 | 证据或缺口 |
| --- | --- | --- |
| 客户端伪造身份 | 服务端 token→principal，忽略 X-Role | API 测试 |
| 跨工作区取数 | 所有业务查询先校验 tenant/request 归属 | API 返回 404，不泄露资源存在性 |
| 采购员自行审批 | buyer/approver 分离；创建人与审批人不同 | 自批、角色伪造测试 |
| 文档 Prompt Injection | 解析只提字段；文档没有 authority；模型仅有 3 个只读工具 | 静态注入及 mock 模型工具越权测试；不是通用免疫证明 |
| 模型写订单/执行 shell | 模型工具白名单不提供任何此类工具 | 请求未知工具返回 TOOL_POLICY_DENIED |
| 金额幻觉 | Decimal、字段 Unknown、确定性总价 | 金额边界/未知传播测试 |
| 人工改价伪装原文 | 新版本 + manual evidence + reason | 历史版本与再次确认测试 |
| 源文件被替换 | 实际文件 SHA-256 校验 | 文件篡改测试 |
| 旧审批被用于新方案 | 版本/证据/政策/ERP 指纹快照 | 数量、报价、政策、目标变化测试 |
| 审批过期或撤权 | 预留与第一次写前校验 | 过期、撤权、慢查询期间过期测试 |
| 重复外部创建 | 本地唯一 operation + 远端 mock 唯一键 + 只读恢复 | 重放、并发、丢回执测试；真实 ERP 结果按具体提交和合成沙箱记录判读，不认证生产 ERP |
| 伪造远端成功 | 比较快照、公司、单位、金额等 | 回执不匹配测试 |
| 超大/恶意 XLSX | 压缩规模、条目数、路径与外链限制；公式不执行 | 恶意 ZIP/公式测试；不是完整沙箱 |
| 恶意 PDF | 2 MiB/10 页限制、文本层处理、独立解析进程 CPU/内存/墙钟限制 | 没有内核系统调用隔离，仍不是完整沙箱 |
| 网络正文过大 | Content-Length 预检、流式正文累计字节 cap、multipart 异常临时文件关闭 | 上游缓冲、慢上传与跨实例速率仍需部署控制 |
| 凭据泄露 | 服务端配置；模型不获得 ERP 凭据；常见异常仅返回错误码 | 没有独立 secrets scanner/渗透测试验收 |
| 网页 XSS | 自有 UI 插入前转义，根页面 CSP、不执行模型 HTML | 尚未通过真实浏览器攻击 E2E |
| Agent 循环 | 模型/工具数量、上下文和响应尺寸上限，HTTP 超时 | 已有工具预算测试；当前 wall-time 不是进程硬杀式上限 |
| 事件泄露 | SSE 使用 Bearer header、租户校验、不把 token 放 URL | 尚未完成生产断线/重放/事件数量压力验证 |
| 系统管理员修改审计 | 服务层只追加，审计落库 | 管理员可改 DB；无 WORM/签名/不可抵赖性 |
| SaaS 生产安全 | 默认仅回环地址；不开放真实 ERP 写入 | 缺 SSO、TLS 入口、速率限制及生产审计保留/删除/灾备验收；本地配对备份不能替代生产灾备 |

## 不可信内容和权威数据

原文和模型输出只是数据；审批状态来自业务数据库及权限服务。政策由具备 approver 权限的服务端发布不可变租户版本，支持预约生效；普通报价上传不能修改政策。LLM 解释的证据 ID 存在性校验不证明解释语义正确。企业规则、报价确认与授权不可由模型文本覆盖。

## 下一道安全验收门

解析进程资源限制已增加，但在接收非合成文件前仍需独立部署级隔离/安全评估；在接入测试 ERP 前，验证独立服务账号与最小权限，建立真实唯一字段并校验映射；在任何对外展示部署前，通过原生前端构建、严格浏览器 E2E、依赖审计和部署配置审查。历史工程测试数不能证明本轮或生产安全；以当前提交的明确验收记录为准。


## 阶段十二更新

普通 CSV/XLSX 路径加入持久映射预览、版本绑定与确认幂等，表格源内容始终不具有业务授权。
网络入口在 multipart 解析/spool 前累计限制读取字节，即使没有 Content-Length；反向代理/ASGI 服务器的提前缓冲、连接数与慢上传仍需独立限流。
精确的解析限制、失败行为及未提供的操作系统隔离保证见 [阶段十二安全边界](stage12-tabular-import.md#安全边界)。
不要将进程限制、Python 审计钩子等同 seccomp、容器或内核级沙箱。


## 恢复诊断边界

恢复会撤销旧会话／邀请并进入 pilot 专用的 `RECOVERY`；诊断 UI/API 不授予新权限或替代离线操作员审核。待处理 hold、源文件完整性与 ERP 差异属于只读证据，不能释放永久 hold、修改审批、自动重放或创建替代草稿。缺失 ERP 记录不证明没有外部副作用；受限字段比较也不是通用对账或安全认证。阶段十六的本地验证与基线 CI 必须分别记录，独立安全审查仍未完成。
